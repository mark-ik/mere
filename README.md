# servitor

Capability-scoped resident helpers for graph applications: identity, grants,
proposals, attribution.

A servitor is a resident helper with an identity, a capability grant, and the
right to propose changes through a validating gate. Installed extensions and
local agents share one authority model: a servitor cannot exceed its grant,
and everything it does is attributed and revertible.

This release reserves the name; the crate is under design.
