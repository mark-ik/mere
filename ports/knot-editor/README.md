# knot-editor

Name reservation for **knot-editor**, the crates.io package spelling available
to [Knot](https://github.com/merely-made/mere/tree/main/ports/knot), Mere's
standalone-capable local-first Djot editor.

The implementation remains in `ports/knot`. This crate contains no editor code,
does not create a second editor, and does not rename the Knot product.

## Status

**Name reservation.** No implementation yet.
