# Knot K0 through K7 receipt

Date: 2026-07-27

## Claim

Knot is a Mere workspace port with a real Graphshell endpoint. It owns
files-in-place projection, a sealed vault, grant-scoped search, encrypted
single-writer sync, format-selectable writers, and the editor adapter. Source
bytes, vault keys, and edit state remain with the endpoint.

## Executed proof

Focused verification:

```powershell
cargo test -p knot
cargo clippy -p knot --all-targets --no-deps -- -D warnings
cargo check -p knot --all-targets
```

Twenty-eight tests pass. They cover content classes, disk authority and
rename-stable identity, native watcher attribution and revocation, vault
sealing and lock behavior, grant-scoped disk/vault search, memory and real
p2panda convergence, explicit same-document writer refusal, format fixed
points, untouched-file preservation, byte-exact canonical `.knot`, and
Cambium-backed command, IME, affinity, readout, undo, and save behavior.

The dependency-inclusive warning-denying Clippy command reaches existing
`numen::FieldId` and `CouplingId` `new_without_default` findings before Knot.
Knot's own `--no-deps` warning-denying gate passes. `cargo check -p knot
--all-targets` also passes.

K7 currently resolves the completed Cambium primitive from the dirty Genet
working tree through Mere's local Cargo patch. Until that Genet slice reaches
`main`, this is a local integration receipt rather than a clean-checkout one.

## Cross-process receipt

The host and three endpoints were built independently:

```powershell
# repos/mere
cargo build -p graphshell --bin g4_sessions
cargo build -p knot --bin knot_endpoint

# repos/turnstone
cargo build --bin graphshell_endpoint

# repos/isometry
cargo build -p isometry-graphshell --bin isometry_endpoint
```

One product-neutral host then mounted all three endpoint processes:

```text
mounted 4 sessions from 3 endpoints into ports\knot\docs\receipts\k0_session_switch.html
```

The four sessions are Turnstone's browsing graph, Isometry's player overmap and
tile board, and Knot's authoring fixture. Repeating the generation produced the
same SHA-256 digest:

```text
28459BF5591CFB67CCCAD09BF5D2AFCD1F829FADE644C724F1E4DEBC6A076E60
```

The [HTML receipt](receipts/k0_session_switch.html) is the generated proof
artifact.
